协议架构

Kimi 客户端 API 是双协议架构：

协议路径用途特征
REST/api/*账户、设备、文件等外围能力Ktor Client + OkHttp, application/json
Connect-RPC/apiv2/*聊天、社区、IM、会员等全部核心业务application/connect+json，纯 JSON 无二进制 protobuf

Chat、Moment、Feed、IM 等核心业务全部走 Connect-RPC。研究核心业务即研究 Connect-RPC。

快速开始

curl -X POST https://www.kimi.com/apiv2/kimi.gateway.chat.v1.ChatService/ListChats \ -H "Content-Type: application/connect+json" \ -H "Authorization: Bearer $TOKEN" \ -H "x-msh-platform: android" \ -d '{"pageSize": 20}'
