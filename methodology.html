1. 协议架构总认知

协议路径用途特征

2. 静态研究方法

2.1 反编译工具链

工具产出用途
APKTool Msmali 代码 + 资源拿到全部混淆后的类与方法
jadx近似 Java 源码比 smali 可读性高，混淆类仍需还原
R8 mapping.txt混淆映射还原混淆类名/方法名的唯一钥匙

本研究使用 APKTool M 产出 smali，无 mapping.txt，类型还原采用启发式。

2.2 字符串常量提取 API 全景

proto 的 RPC 服务信息没有目录结构，但关键字符串保留在 smali 常量池里：

① 服务名 grep -rhoE "[a-z0-9_]+\.[a-z0-9_]+\.v[0-9]+\.[A-Za-z0-9]+Service" smali*/ --include="*.smali" ② 方法名（RPC URL） grep -rhoE "[A-Za-z0-9_.]+Service/[A-Za-z0-9]+" smali*/ --include="*.smali" ③ message 完整类名 grep -rhoE "com\.moonshot\.kimi\.proto\.[A-Za-z0-9_.$]+" smali*/ --include="*.smali" ④ 字段名（从 toString() 方法体提取） "Feed(feedType=" + v + ", feedId=" + v + ", _moment=" + v + ", _interestCard=" + v + ")" ⑤ 字段类型（从构造函数签名提取） .method public constructor <init>(Lor/a6;Ljava/lang/String;Lor/ff;Lor/ra;Lor/ci;)V

2.3 混淆类还原

无 mapping.txt 时，还原依赖三条线索：

  • 字段名语义：_moment 字段类型几乎必然是 Moment
  • message 类名前缀：Moment._content → 优先匹配 MomentContent
  • cast 字符串："null cannot be cast to non-null type com.moonshot.kimi.proto.moment.v1.UnMuteResponse" 直接给出映射

精确还原仍依赖 mapping.txt。已导出混淆类清单（620 个混淆类 + 推测映射）。

3. 调用方法（Connect-RPC）

3.1 请求构造

POST /apiv2/{服务全限定名}/{方法名} HTTP/2 Host: www.kimi.com Content-Type: application/connect+json Authorization: Bearer {accessToken} x-msh-platform: android x-msh-device-id: {设备指纹ID} x-msh-session-id: {会话ID} x-msh-version: 3.0.8 R-Timezone: GMT+08:00 {"字段名": 值, ...}

3.2 流式方法

Chat、SubscribeMessageStream 等流式方法响应为按行分隔的 JSON 事件流：

{"eventOffset": 1, "type": "heartbeat"} {"eventOffset": 2, "type": "chunk", "text": "你好"} {"eventOffset": 3, "type": "done"}

断点续传靠递增 eventOffset。误用 unary 调用流式方法，服务端返回 "event stream, 请使用 stream 方法请求"。

3.3 认证链

  • Token 获取：account.gateway.v1 的 LoginWithSMS / LoginWithThirdParty / ScanLoginQRCode
  • Token 注入：Authorization: Bearer {token}，401 时客户端自动 refresh
  • 风控头：X-Msh-Shield-Data（TrustDecision 设备指纹）是请求级身份的一部分

4. 验证方法

4.1 静态验证

  • 方法名 ↔ Request/Response 类名对应关系
  • 字段名 ↔ 构造函数参数顺序一致性抽查

4.2 动态验证

  • 手机端：mitmproxy + 自建 CA 证书抓取真实请求
  • PC 端：curl 构造请求观察响应
  • Hook 端：Frida hook ConnectRpcClient 打印请求/响应

4.3 边界验证

  • 流式 vs unary：对 stream 方法用 unary 调用观察报错文案
  • 分页：nextPageToken / isLastPage 字段驱动循环翻页
  • 权限：无 token / 过期 token 访问观察 401 行为
